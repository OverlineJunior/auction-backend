# Tech Stack

- **Language:** TypeScript
- **Runtime:** NPM
- **Framework:** Express
- **ORM:** Prisma
- **Database:** PostgreSQL
- **Hosting:** AWS[^1]

[^1]: We'll start with Railway first, then migrate to AWS once the project is ready.
